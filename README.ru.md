# Awesome New API Grants

[English](README.md) · **Русский** · [中文](README.zh-CN.md)

Каталог AI API сервисов с бесплатными квотами и бонусным балансом.

**Все ссылки на сервисы — реферальные ссылки автора. Автор может получить бонус за регистрацию.**

Данные предоставлены автором на 6 ноября 2026 года и не проверены независимо. Условия и доступность моделей могут меняться. Суммы в долларах и юанях обозначают внутренний баланс API; возможность вывода денег не заявляется.

| Сервис / регистрация | Бонусы по данным автора |
| --- | --- |
| [PixRouter](https://pixrouter.com/sign-up?aff=sI5W) | Много бесплатных моделей с хорошей квотой. |
| [AgentRouter](https://agentrouter.org/register?aff=idPd) | Около $175 на модели ChatGPT, ещё $50 по реферальной ссылке и $25 ежедневно. Уточните, суммируются ли бонусы. |
| [KKToken](https://kktoken.cc/sign-up?aff=SLH0) | Модели пока недоступны, ожидается их добавление. Около $20 ежедневно; возможный бонус $50 за вход требует уточнения. |
| [FX Qidian](https://fxqidian.de5.net/sign-up?aff=ISaZ) | Около $15 за регистрацию по ссылке и $3–5 ежедневно. По данным автора, есть недорогие GLM 5.3 Flash и DeepSeek V4 Flash; точные названия и цены уточняйте на сайте. |
| [Berf AI](https://ai.berf1.cn/sign-up?aff=Uq9b) | Баланс в юанях. По оценке автора, бонуса хватает примерно на 50 млн токенов DeepSeek за регистрацию и 12 млн ежедневно. Объём зависит от тарифа и соотношения входных и выходных токенов. |
| [VSLLM](https://vsllm.cc/register?aff=9A3D) | Ещё один сервис из подборки. Бонусы и модели уточняйте на сайте. |

Некоторые сервисы требуют авторизацию через GitHub и аккаунт возрастом **не менее 6 месяцев**. По оценке автора, это касается примерно половины подборки; проверяйте требования каждого сайта.

Откройте ссылку, проверьте текущие условия, зарегистрируйтесь и убедитесь в начислении баланса. Ежедневный бонус может требовать ручной отметки.

Условия изменились? Создайте issue с названием сервиса и актуальными данными. Не публикуйте API ключи и другие секреты.
